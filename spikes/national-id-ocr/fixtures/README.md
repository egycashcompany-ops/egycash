# Fixtures

Two sets, one shape. `manifest.schema.json` defines both, which is the whole point: real
anonymized cards drop into `real/` and the harness measures them with **no code change**.

```
fixtures/
  synthetic/   generated by `make fixtures` — committed, safe, and NOT evidence about real cards
  real/        anonymized real cards — NEVER committed (see .gitignore)
```

## Never commit a real National ID

`real/` is git-ignored except for this note. A National ID card is a person's name, address,
ID number, religion, marital status and photograph — special-category personal data that must not
enter version control, where it is effectively permanent and readable by everyone with repo
access. Mount the directory at run time instead:

```bash
make measure-real          # mounts ./fixtures/real read-only into the container
```

## Anonymizing a real card

The goal is a card that is **photographically real but personally meaningless**: same substrate,
same fonts, same print, same camera path — different person. That is what makes the measurement
predictive, and it is why a synthetic render cannot substitute for it.

1. Replace the ID number with a structurally valid but unissued one — keep the century digit,
   a plausible birth date and a real governorate code, and change the serial. The pipeline's
   structural check must still pass, or you will be measuring the rejection path instead.
2. Replace the name and address with equally long Arabic text. Length matters: a short
   substitute makes the field easier than the original.
3. Mask the photograph and the signature strip.
4. Keep everything else untouched — the background, the wear, the glare, the angle. Those are
   the difficulty. Removing them turns a real fixture into an optimistic one.
5. Write the ground truth by reading the **anonymized** card, exactly as printed.

Ten cards covering the messy cases (angled, glare, worn, low light) is worth far more than fifty
clean scans — the clean ones tell you what you already know.

## Manifest

```json
[
  {
    "id": "real-001",
    "front": "real-001-front.jpg",
    "back": "real-001-back.jpg",
    "quality": "harsh",
    "source": "real-anonymized",
    "truth": {
      "fullNameAr": "…",
      "address": "…",
      "nationalId": "29001011201234",
      "occupation": "…",
      "religion": "مسلم",
      "maritalStatus": "متزوج",
      "nationalIdExpiry": "2030-05-12"
    }
  }
]
```

Transcribe truth **as printed** — do not normalize the orthography. The scorer applies the same
Arabic fold the API uses for search, so a hamza variant is already forgiven in the `normalized`
column and still visible in `exact`. Normalizing by hand would hide a real difference between the
two metrics.

Omit any field a particular card does not carry; omitted fields are not scored rather than counted
as failures.

## Before measuring a new set

```bash
make check FIXTURES=fixtures/real
```

Real cards will not share the synthetic geometry. This verifies every field box lands on text and
names the ones that do not — because a misplaced box returns an empty string, which in an accuracy
report is indistinguishable from "the model cannot read Arabic". Fix the boxes in
`src/nidocr/layout.py` (use `--overlay` to see them) *before* trusting any accuracy number.
